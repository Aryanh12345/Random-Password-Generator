# 🔐 Random Password Generator

A simple and interactive **Random Password Generator** built using **HTML, CSS, and JavaScript**.

This project allows users to generate random passwords quickly with a simple and easy-to-use interface.

## 🌐 Live Demo

👉 **[Visit Random Password Generator](https://aryanh12345.github.io/Random-Password-Generator/)**

## 🚀 Features

- 🔐 Generate random passwords
- 🔢 Includes numbers
- 🔤 Includes uppercase and lowercase letters
- 🔣 Includes special characters
- 📋 Copy generated password
- ⚡ Generate passwords instantly
- 🎨 Clean and modern interface
- 📱 Responsive design
- 💻 Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Application structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Password generation and interactions
